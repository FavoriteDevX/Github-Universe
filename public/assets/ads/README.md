# House of MAC ad banners

Put the ad banner images here with these exact names (JPG):

| File | Where it shows |
|---|---|
| `macbook-air.jpg` | "Mac" billboard + store carousel |
| `macbook-neo.jpg` | "MacBook Neo" billboard + carousel |
| `m1.jpg` | "Apple M1" billboard + carousel |
| `macos.jpg` | "macOS" billboard + carousel |
| `mac-apps.jpg` | "macOS apps" billboard + carousel |

Any aspect ratio works: billboards resize to the banner. To add more banners to
the in-store carousel, add entries to `ads.json`. Missing files simply keep the
generated board with the official logo.

Apple ads and product photos are copyrighted by Apple (and images taken from
news sites belong to those sites): only publish them if you have the right to.
