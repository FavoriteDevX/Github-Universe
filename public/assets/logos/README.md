# Official logos (optional)

Some companies asked the Simple Icons project to remove their logos, so the
Multiverse shows their name as text. If you have the right to use their
official logo (for example from the company's press kit), save it here and it
replaces the text on billboards, HQ signs and skyline towers:

| Company | File name |
|---|---|
| OpenAI | `openai.svg` (or `openai.png`) |
| Microsoft | `microsoft.svg` |
| Microsoft Azure | `azure.svg` |
| AWS | `aws.svg` |
| Amazon | `amazon.svg` |
| Oracle | `oracle.svg` |
| Adobe | `adobe.svg` |
| LinkedIn | `linkedin.svg` |
| Salesforce | `salesforce.svg` |

Logos are trademarks of their owners.
